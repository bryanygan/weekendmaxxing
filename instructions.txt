## Phase 1 — LLM Utility Layer

```
You are implementing the LLM utility layer for a local-first travel deal hunter.

- POSTs to http://localhost:11434/api/chat (configurable via settings.py)
- Uses the model from settings.LOCAL_LLM_MODEL (default: "llama3.1:8b")
- Sets stream=False
- Returns the string content of the response message
- Raises a descriptive RuntimeError if the HTTP response is not 200
- Raises a descriptive RuntimeError if the response JSON is malformed

- Strips markdown code fences (```json, ```)
- Attempts json.loads() on the full stripped string
- If that fails, uses regex to find the first [...] block (for arrays)
- If that fails, uses regex to find the first {...} block (for objects)
- If all attempts fail, prints a warning with the first 200 chars of raw and 
  returns an empty list
- Never raises an exception — always returns list, dict, or []

--- tests/test_phase1.py ---
Write pytest tests that:
1. test_call_llm_returns_string: calls call_llm with a simple prompt asking for

5. test_extract_embedded_json: passes prose text with a JSON array buried in it,

All tests must be self-contained. Import call_llm and extract_json from their
```

```
    - stores constraints

    - Returns list of (outbound_date, return_date) tuples for the next N weekends
    - Outbound is Friday OR Saturday (return BOTH for each weekend)
    - Return is always Sunday of the same weekend
    - Dates as "YYYY-MM-DD" strings
    - Never return dates in the past

  METHOD: async scrape_and_parse(self, origin, dest_city, dest_iata,

    - Calls scrapers.google_flights.fetch_raw(origin, dest_iata, outbound, return)
    - If raw text is empty, returns []
    - Calls utils.llm.call_llm with a system prompt and user prompt
    - System prompt: "You are a flight data extraction agent. Extract all visible

        price_usd (number), airline (string), outbound_depart (HH:MM),
```

## Phase 5 — Cost Agent & Deal Scorer

**Goal:** Every deal gets a realistic total budget estimate and a 0–100 score that determines which deals surface.

### Agent Prompt

```

--- agents/cost_agent.py ---
CLASS: CostAgent
  __init__(self)  # no constraints needed

  METHOD: estimate_transit(self, city: str) -> dict
    - Calls call_llm with:
      System: "You are a travel cost estimator. Always respond with ONLY valid JSON.
               No markdown, no explanation."
      User: "For a weekend trip to {city} from a major US airport, estimate costs 
             in USD as a JSON object with these exact keys:
             airport_transit_one_way (cheapest public transit option, number),
             rideshare_one_way (Uber/Lyft estimate, number),
             daily_food_budget_low (number), daily_food_budget_mid (number),
             avg_activity_cost (one typical paid activity, number),
             public_transit_day_pass (number or null if city has no good transit)"
    - Uses extract_json to parse response
    - If parsing fails, returns safe hardcoded defaults:
        {"airport_transit_one_way": 15, "rideshare_one_way": 35,
         "daily_food_budget_low": 40, "daily_food_budget_mid": 65,
         "avg_activity_cost": 25, "public_transit_day_pass": 10}
    - Clamps all numeric values to reasonable ranges:
        transit: 2–100, rideshare: 10–120, food_low: 20–100, 
        food_mid: 40–150, activity: 0–200

  METHOD: compute_full_budget(self, deal: dict) -> dict
    - Calls estimate_transit for deal["destination"]
    - Computes estimated_extras:
        (airport_transit_one_way * 2)          ← to/from airport
        + (daily_food_budget_mid * 2)          ← 2 days
        + avg_activity_cost                    ← 1 activity
    - Adds to deal:
        transit_estimates: the full transit dict
        estimated_extras: rounded to 2 decimal places
        estimated_total: total_trip_cost + estimated_extras, rounded to 2dp
    - Returns the mutated deal

--- orchestrator/deal_scorer.py ---
Implement score_deal(deal: dict, constraints: dict) -> float
  Returns a score from 0.0 to 100.0 using this weighted formula:

  PRICE SCORE (40 points):
    budget_cap = max_flight_roundtrip + (max_hotel_per_night * 2)
    price_ratio = total_trip_cost / budget_cap
    price_score = max(0, 40 * (1 - price_ratio))

  NONSTOP SCORE (20 points):
    0 layovers → 20 pts
    1 layover  → 10 pts
    2+ layovers → 0 pts

  HOTEL QUALITY SCORE (20 points):
    rating = best_stay.rating (default 3.0 if missing)
    hotel_score = (rating / 5.0) * 20

  TIME AT DESTINATION SCORE (10 points):
    hours = hours_at_destination (default 24)
    time_score = min(10, (hours / 48) * 10)

  RETURN BUFFER SCORE (10 points):
    Parse return_arrive as float hours (e.g. "19:30" → 19.5)
    buffer = max(0, 22.0 - arrive_hour)
    buffer_score = min(10, buffer * 2.5)

  Final: sum all five, round to 1 decimal place
  If any required key is missing, return 0.0 rather than crashing
```

```
CLASS: RecommendationAgent

      User prompt (build dynamically):
        "I'm flying into {city} and arriving around {arrive_time} on {outbound_day}.

         4. ONE PRO TIP specific to this city for a short trip

    - Adds deal["recommendations_city"] = city

    - Catches any exception per deal (logs warning, sets recommendations to
```

## Phase 8 — Master Pipeline & Scheduler

**Goal:** All agents are wired together. One command runs the full end-to-end pipeline. The scheduler runs it automatically every 6 hours and on Tuesday mornings.

### Agent Prompt

```
You are implementing the master pipeline and scheduler for a weekend deal hunter.

--- orchestrator/pipeline.py ---
FUNCTION: run_pipeline(aggressive=False) -> dict
  Returns a summary dict: {started_at, finished_at, deals_found, deals_notified}

  STEPS (in order, each step logs its start):
  1. Load config/destinations.json and config/constraints.json
  2. Init state manager DB
  3. Record started_at = datetime.now().isoformat()
  4. Instantiate FlightAgent, HotelAgent, CostAgent, RecommendationAgent
  5. Run FlightAgent.run(destinations) — await with asyncio.run()
     If result is empty, log "[Pipeline] No valid flights found. Aborting." 
     write no-deals dashboard and return early.
  6. Run HotelAgent.run(flight_deals) — await with asyncio.run()
     If result is empty, same early abort.
  7. For each enriched deal, call CostAgent.compute_full_budget(deal)
  8. Score each deal with score_deal(deal, constraints)
  9. Filter: keep only deals with score >= SCORE_THRESHOLD (default 55, 
     override with env var DEAL_SCORE_THRESHOLD)
  10. Sort by score descending
  11. Take top 10 deals
  12. Call RecommendationAgent.generate_batch(top_deals)
  13. Separate into new deals (not duplicate) and seen deals
  14. For new deals only: save_deal(), then write_dashboard()
  15. Log run summary: X flights → Y with hotels → Z scored → N new
  16. Record finished_at, call log_run()
  17. Return summary dict

  - Wrap the entire pipeline in try/except
  - On any unhandled exception: log full traceback, write no-deals dashboard,
    return summary with deals_found=0, deals_notified=0
  - Individual agent failures (already handled in each agent) do not abort pipeline

  - Uses APScheduler BlockingScheduler
  - Job 1: run_pipeline() every 6 hours
  - Job 2: run_pipeline(aggressive=True) every Tuesday at 09:00 local time
  - On startup: log all scheduled jobs with their next run times
  - Catches KeyboardInterrupt gracefully: logs "Scheduler stopped."
  - Runs run_pipeline() ONCE immediately on startup before the scheduler starts
```
